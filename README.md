# Koshey

Пустой проект Unity без игровых сцен, скриптов и сторонних пакетов.

## Открытие

1. Установите Unity Editor **6000.0.23f1** (Unity 6) через Unity Hub.
2. В Unity Hub выберите **Add → Add project from disk** и укажите корень этого репозитория.
3. Откройте проект. Unity создаст локальные настройки и каталог `Library` при первом запуске.
4. Создайте сцену через **File → New Scene** и сохраните её в `Assets`.

`Assets`, `Packages` и `ProjectSettings` хранятся в Git. Генерируемые каталоги исключены через `.gitignore`. Новые ресурсы коммитьте вместе с их `.meta`-файлами.

Структура проекта подготовлена без запуска Unity Editor; открытие и сборка в редакторе пока не проверены.
