# Koshey — 2D-прототип

Небольшой платформер с видом сбоку для Unity **6000.0.23f1**.

## Запуск

1. Добавьте корень репозитория через Unity Hub → Add project from disk.
2. Откройте `Assets/Scenes/Prototype.unity` и нажмите Play.
3. При запросе Active Input Handling используйте **Input Manager (Old)** или **Both**: прототип использует встроенный `UnityEngine.Input`.

## Управление

- **A / D** или **← / →** — движение.
- **Space**, **W** или **↑** — прыжок; короткое нажатие даёт более низкий прыжок.
- **R** — возврат на старт. Падение в пропасть также возвращает на старт.

Доберитесь до зелёного флага справа. Есть платформы, пропасти, камера с плавным следованием, небольшой допуск прыжка после схода с края и буфер нажатия перед приземлением.

Уровень и простая графика создаются при запуске сцены скриптом `Assets/Scripts/SideScroller.cs`; внешние ресурсы не нужны. Слой 8 используется для поверхности платформ. Сцена включена в Build Settings.

## Проверки

Unity Editor в облачной среде не установлен: открытие сцены, компиляция, игровой процесс и сборка пока не проверены в редакторе. Проверьте в Play Mode движение, короткий/длинный прыжок, посадку на платформы, падение, финиш и перезапуск.
